================================================================================
KEY DESIGN PATTERNS
================================================================================

Monorepo:
  - pnpm workspaces with Turborepo task orchestration
  - Shared @bruce/* packages imported by all modules
  - Per-module apps with independent HTTP servers + Temporal workers

Database:
  - Drizzle ORM for type safety
  - RLS (Row-Level Security) for automatic data isolation by account
  - PostgreSQL pooling + connection management

Agents:
  - Specs in modules/ (SKILL.md + JSON schemas)
  - Runtime loads + executes agents with structured validation
  - Automatic retry with exponential backoff

Workflows:
  - Temporal.io for durable, resumable async execution
  - Per-module task queues
  - Activities call AgentRunner
  - Workflows orchestrate agent sequences

APIs:
  - Hono (lightweight HTTP framework)
  - OpenAPI/Zod for automatic documentation + validation
  - JWT auth + RLS context per request
  - Async pattern: POST triggers workflow, GET polls status
