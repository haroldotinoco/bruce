# Naming Policy

## Hard Rules (Non-Negotiable)

1. **No Trademarked Terms**: Brand name must not be identical or confusingly similar to existing registered trademarks
2. **Domain Available**: Primary preference for .com domain. If unavailable, .io or .co acceptable only with client approval
3. **No Generic Terms**: Avoid purely generic terms (e.g., "Freelance", "Connect") unless heavily qualified
4. **No Profanity**: Screen all candidate names for slurs, profanity, or offensive meanings in major languages (English, Spanish, French, German, Mandarin)
5. **Pronounceable**: Name must be pronounceable for international audience (no excessive consonant clusters or ambiguous letter combinations)

## Soft Guidelines (Strategic Preferences)

1. **Length**: Prefer 1-2 syllables, maximum 3 syllables
2. **Memorability**: Name should be memorable after one hearing
3. **Ownable**: Name should own a specific positioning or concept, not generic or descriptive
4. **Extensibility**: Name should allow for word/brand mark combinations (can add prepositions, articles)
5. **Cultural Neutrality**: Avoid names with strong associations to specific cultures that may alienate other segments

## Domain Checking Requirements

For all top 3 candidates:
1. Check .com availability (primary)
2. Check .io, .co availability (fallback)
3. Check for typosquatting risk (common misspellings registered by squatters)
4. Verify domain registration history (avoid domains with negative history)

## Trademark Screening Process

1. **Name similarity search**: Search USPTO, international trademark databases, and Google for exact/similar marks
2. **Risk classification**:
   - **Safe**: No similar trademarks, clear ownership possible
   - **Caution**: Similar marks exist but in different categories/industries
   - **Risk**: Similar marks in same/adjacent categories
   - **Blocked**: Identical or confusingly similar trademark already registered
3. **Manual review required**: Any "Caution" or "Risk" flagged names require human review before final selection

## Evaluation Criteria

All candidate names scored against:
1. Strategic alignment (does name reinforce positioning?)
2. Memorability (easy to remember, spell, pronounce?)
3. Domain availability (is .com available?)
4. Distinctiveness (unique vs. competitors?)
5. Extensibility (can it work in different contexts?)
6. International readiness (no offensive meanings in major languages?)

## Escalation Path

- **Blocked names**: Rejected immediately; alternative suggested
- **Risk names**: Escalated to stakeholder decision; proceed only with explicit approval
- **Caution names**: Noted in brand book; proceed with acknowledgment of risk
